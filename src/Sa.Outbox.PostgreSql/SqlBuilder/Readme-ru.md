# SqlBuilder

## Обзор

В этой папке находятся типы, отвечающие за генерацию и параметризацию всех SQL-запросов, используемых подсистемой исключающего почтового ящика (outbox) на базе PostgreSQL. В отличие от папки `Commands` (которая преобразует высокоуровневые операции в конкретные `NpgsqlCommand`-вызовы), `SqlBuilder` владеет **самими SQL-шаблонами** и инфраструктурой, обеспечивающей их работу при высоких нагрузках.

## Структура файлов

| Файл | Назначение |
|---|---|
| `SqlOutboxBuilder.cs` | Основной класс, содержащий все строки SQL-шаблонов, а также вспомогательные методы для динамической генерации списков значений (вставка ошибок, завершение доставки). Для эффективности по памяти использует пулированный `StringBuilder`. |
| `SqlParam.cs` | Статический класс с именованными константами для каждого заполнителя SQL-параметра (например, `@tnt`, `@gr`, `@frm`). Обеспечивает консистентность во всех запросах. |
| `Setup.cs` | Метод расширения DI (`AddOutboxSqlBuilder`), регистрирующий `ObjectPool<StringBuilder>` и `SqlOutboxBuilder`. |

## Шаблоны

Все шаблоны строятся при конструировании с использованием имён таблиц/столбцов из `PgOutboxTableSettings`, поэтому результирующий SQL адаптируется под конкретную схему БД потребителя.

### Статические шаблоны (константные строки)

| Поле | Описание |
|---|---|
| `SqlBulkMsgCopy` | Двоичный COPY-IN для массового вставки сообщений из STDIN |
| `SqlCreateTypeTable` | Создаёт таблицу справочника типов, если отсутствует |
| `SqlSelectType` | Выбор всех строк из таблицы типов |
| `SqlInsertType` | Вставляет новую запись типа с `ON CONFLICT DO NOTHING` |
| `SqlCreateOffsetTable` | Создаёт таблицу отслеживания смещений, если отсутствует |
| `SqlInsertOffset` / `SqlSelectOffset` / `SqlUpdateOffset` / `SqlInitOffset` | Операции CRUD для отслеживания смещений групп потребителей |
| `SqlLockOffset` | Advisory-замок (`pg_advisory_xact_lock`) для сериализации записи смещений |
| `SqlLockAndSelect` | Запрос с CTE: выбирает ожидающие/восстановимые задачи, помечает их как `Processing`, присоединяет таблицу сообщений и возвращает полезную нагрузку. Использует `FOR UPDATE SKIP LOCKED` для безопасного конкурентного потребления |
| `SqlExtendDelivery` | Продлевает TTL блокировки для текущей обрабатываемой задачи |
| `SqlLoadConsumerGroup` | Массово вставляет задачи из таблицы сообщений в очередь задач, возвращая ID последней вставленной записи |

### Динамические шаблоны (генерируются при вызове)

| Метод | Описание |
|---|---|
| `SqlError(int count)` | Генерирует многострочные INSERT-запросы для записей об ошибках (параметризуется по количеству) |
| `SqlFinishDelivery(int count)` | Завершает пакет доставки: вставляет лог-записи, затем обновляет соответствующие записи задач |

Оба динамических метода используют `ObjectPool<StringBuilder>`, чтобы избежать выделений памяти при высокопроизводительной пакетной обработке.

| `FromDate` / `ToDate` | `@frm` / `@to` | Границы временного диапазона |

| `TransactId` | `@trn` | Идентификатор транзакции/сессии |
| `Offset` | `@offset` | Позиция курсора для постраничной навигации |
| `Limit` | `@lim` | Макс. строк за батч |
| `LockOffset` | `@lck_id` | Числовой ID advisory-замка |

## Регистрация в DI

Метод `Setup.AddOutboxSqlBuilder` подключает три компонента:

1. `ObjectPoolProvider` → `DefaultObjectPoolProvider`
2. Пулированный `ObjectPool<StringBuilder>` (начальная ёмкость 1024) — повторно используется при динамической генерации SQL для снижения нагрузки на сборку мусора
3. Синглтон `SqlOutboxBuilder`

Также делегирует вызов `AddPgOutboxSettings` для регистрации настроек таблиц/столбцов.

## Примечания к дизайну

- **Пулениый StringBuilder** — Многострочные списки значений (ошибки, доставки) используют `ObjectPool<StringBuilder>`, чтобы избежать выделений памяти при высокопроизводительной пакетной обработке.
- **Advisory-замки** — Запись смещений сериализуется через `pg_advisory_xact_lock`, что предотвращает состояния гон без тяжёлых табличных блокировок.
- **SKIP LOCKED** — Выбор задач использует `FOR UPDATE SKIP LOCKED` PostgreSQL, позволяя нескольким потребителям безопасно конкурировать за работу.
- **ON CONFLICT DO NOTHING** — Идемпотентные вставки защищают от повторной обработки при повторах.
- **Шаблонизация схемы** — Каждый шаблон разрешает имена таблиц/столбцов из `PgOutboxTableSettings` при конструировании, поэтому рантайм-конкатенация строк не требуется.
